# Audio Description Scripts for Stockdash

Here are three script variations optimized for ElevenLabs text-to-speech. Choose the one that best fits your portfolio video style.

## Recommended Voice Settings

- **Voice**: "Adam" (Deep, narration) or "Rachel" (Clear, professional) available in ElevenLabs.
- **Stability**: 50%
- **Similarity Boost**: 75%

## Option 1: The "Elevator Pitch" (30 Seconds)

**Best for:** Short social media clips or Intro segments.

"Meet Stockdash—the ultimate tool for modern investors. I built this full-stack application to bridge the gap between complex market data and clear, actionable insights.

Powered by Angular 17 and Flask, it delivers real-time tracking for stocks and mutual funds right to your fingertips. With interactive Highcharts visualizations and a sleek, custom-built dark mode, analyzing market trends has never looked this good.

Deployed on Microsoft Azure for lightning-fast performance, Stockdash isn't just a tracker; it's your personal financial command center. Check it out today."

## Option 2: The "Professional Walkthrough" (60 Seconds)

**Best for:** Upwork portfolio video or detailed demo.
**Style:** Professional, Explanatory, Confident.

"In the fast-paced world of finance, data is everything. That's why I created Stockdash—a comprehensive portfolio management platform designed for speed and precision.

Building this application required a robust full-stack approach. On the front end, I utilized Angular 17 to create a responsive, single-page application that feels seamless on any device. I integrated Highcharts to turn raw data into interactive, easy-to-read timelines and sparklines.

The backend is powered by a custom Python Flask API, which aggregates live market data from multiple sources, ensuring you always have the latest numbers.

But performance matters as much as data. That's why I implemented a complete CI/CD pipeline using GitHub Actions to deploy directly to Azure Static Web Apps, ensuring pro-level reliability.

Stockdash demonstrates the power of modern web technologies to solve real-world investment challenges."

## Option 3: The "Technical Deep Dive" (45 Seconds)

**Best for:** Highlighting your engineering skills to technical recruiters.
**Style:** Technical, Precise, Skill-Focused.

"This is Stockdash, a high-performance investment dashboard engineered with the latest web standards.

At its core, the application leverages the power of Angular 17's signals and standalone components for a highly optimized frontend architecture. I implemented lazy loading and OnPush change detection to ensure instant rendering of complex financial datasets.

The backend service is a RESTful API built with Python and Flask, processing data from MFApi and Y-Finance with custom mapping algorithms.

I containerized the deployment process using Azure Static Web Apps, complete with automated build workflows and environment management. The result is a scalable, type-safe, and production-ready application that handles real-time data with ease."
