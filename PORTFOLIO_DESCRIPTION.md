# Stockdash - Financial Portfolio Management Platform

## Project Overview

A sophisticated full-stack web application for tracking and analyzing mutual funds and stocks in the Indian market. Built with modern web technologies and deployed on Microsoft Azure, this platform provides real-time financial data visualization and portfolio management capabilities.

## 🎯 Project Highlights

**Live Application**: Deployed on Azure Static Web Apps with automated CI/CD pipeline  
**Tech Stack**: Angular 17, TypeScript, Flask API, Python, Azure Cloud Services  
**Duration**: Multi-phase development with continuous enhancements  
**Role**: Full-Stack Developer & DevOps Engineer

## 💼 Key Responsibilities & Achievements

### Frontend Development

- Architected and developed a responsive Angular 17 application with lazy-loaded feature modules for optimal performance
- Implemented advanced data visualization using Highcharts with interactive stock price charts, timeline analysis, and sparkline graphs
- Created a sophisticated theming system with multiple color schemes (dark/light modes) using CSS variables and dynamic styling
- Built reusable component library including custom buttons, modals, loading states, and data tables
- Utilized OnPush change detection strategy and efficient pagination for enhanced performance

### Backend Integration

- Developed Flask REST API for serving financial data with proper error handling and validation
- Integrated external APIs including MFApi.in for mutual fund data and yfinance for stock market information
- Implemented efficient data processing pipelines for mapping mutual funds to stock tickers
- Created comprehensive API endpoints for funds, stocks, and timeline data with pagination support

### Cloud Infrastructure & DevOps

- Deployed application to Azure Static Web Apps with production-ready configuration
- Set up GitHub Actions workflow for automated CI/CD pipeline
- Configured build optimization strategies including CSS budget management
- Implemented environment-specific configurations for development and production
- Managed Azure App Service deployment for Flask backend API

### Features Implemented

- **Real-time Stock Tracking**: Live market data with price updates and trend indicators
- **Mutual Fund Analysis**: Comprehensive fund information with performance metrics (1D, 1W, 1M, 3M, 1Y)
- **Interactive Charts**: Historical price and volume visualization with Highcharts
- **Favorites Management**: User-friendly system for tracking preferred stocks and funds
- **Responsive Design**: Mobile-first approach ensuring seamless experience across all devices
- **Theme System**: Dynamic theming with TradingView-inspired dark mode and professional light theme
