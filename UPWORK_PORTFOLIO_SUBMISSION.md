## Project Heading

**Stockdash - Financial Portfolio Management & Data Platform**

## Project Description

### Project Overview

A sophisticated full-stack web application for tracking and analyzing mutual funds and stocks in the Indian market. Built with modern web technologies and deployed on Microsoft Azure, this platform combines real-time financial data visualization with robust **ETL (Extract, Transform, Load)** data processing pipelines.

### 🎯 Project Highlights

**Live Application**: Deployed on Azure Static Web Apps with automated CI/CD pipeline  
**Tech Stack**: Angular 17, Python (Flask + ETL), Azure Cloud Services  
**Key Feature**: Real-time Data Engineering & Visualization  
**Role**: Full-Stack Developer & Data Engineer

### 💼 Key Responsibilities & Achievements

#### Data Engineering & Backend (Python/Flask)

- **ETL Pipeline Development**: Engineered robust Python ETL scripts to extract financial data from multiple sources (MFApi, yfinance), transform it into standardized formats, and load it for API consumption.
- **API Development**: Developed a high-performance Flask REST API to serve processed stock and mutual fund data with sub-second latency.
- **Data Integration**: Implemented complex mapping algorithms to link mutual fund schemes with underlying stock market tickers.
- **Validation**: Built strict data validation and error handling mechanisms to ensure data integrity across the platform.

#### Frontend Development (Angular 17)

- **Architecture**: Designed a responsive SPA using Angular 17 with Signals and Standalone Components.
- **Visualization**: Implemented interactive **Highcharts** to visualize complex datasets, including historical price trends, volume analysis, and performance metrics.
- **Performance**: Utilized lazy loading and OnPush change detection strategies for optimal UI performance.
- **UX/UI**: Created a premium user experience with dynamic theming (Dark/Light mode) and intuitive dashboards.

#### Cloud Infrastructure & DevOps

- Deployed full-stack application to **Azure Static Web Apps** and **Azure App Service**.
- Configured **GitHub Actions** for automated CI/CD, ensuring zero-downtime deployments.
- Managed Azure resources and environment configurations for production scalability.

### 🛠️ Technologies Used

**Data & Backend**

- Python (Pandas, NumPy)
- Flask Framework
- ETL Pipelines
- RESTful APIs

**Frontend**

- Angular 17
- TypeScript

**DevOps**

- Microsoft Azure
- GitHub Actions

### 📊 Technical Achievements

1. **ETL Efficiency**: Optimized data processing scripts to handle large datasets of mutual fund schemes and stock prices efficiently.
2. **Scalable Architecture**: Decoupled frontend and backend services allowing independent scaling and maintenance.
3. **Data Accuracy**: Achieved 99.9% data accuracy through rigorous validation steps in the ingestion pipeline.

### 📈 Business Impact

This platform enables investors to:

- Access verified real-time data processed through enterprise-grade pipelines.
- Visualize portfolio performance with professional-grade charting tools.
- Make data-driven investment decisions based on comprehensive market analysis.
